# MultiBrain Lab

**三つの脳が、一つの身体を動かせるようになるまで。**

ハエの神経配線を使った神経モデルを人型身体へ接続し、強化学習で床から起き上がって立つ過程を観察する実験です。単脳・三脳・脳間通信ありの条件を並列に進め、美少女アバターで成長と失敗を表示します。

> **現在は計画段階です。** この資料には実装コード、学習済み重み、実測結果は含まれていません。

## 比較する条件

| 条件 | 構成 |
|---|---|
| Mono | 一脳で全身を操作 |
| Tri-Symmetric | 三脳の全身操作案を平均 |
| Tri-Body | 三脳が左側・中央・右側を分担 |
| Tri-Linked | 身体分担＋脳間通信 |
| MLP Control | 通常の人工ニューラルネットによる基準 |

調べるのは、立つまでの経験量と実時間、姿勢の安定性、脳同士の協調、通信の有用性です。設計者が与えた身体分担と、学習中に生まれる役割分化は区別します。

## 実装方針

計算環境はRTX 5090＋Ryzen 9 9950X3Dを想定。Python／PyTorch／TorchRL／MuJoCo Warpで学習し、Three.js／VRMで表示します。

MaleCNS v1.0由来の配線を固定し、神経の増幅率と小さな入出力層を学習させます。初版は活動量を連続値で表す簡略モデルです。生きたハエの記憶や意識、実際の発火を再現するという主張はしません。

並列環境は同じモデルへ経験を集めます。独立した再試行とは分けて管理します。並列数と学習日数は、全規模の学習処理を実測して判断します。

## 最初の到達点

床から自力で起き上がり、両足以外を床に触れずに10秒立つことを課題にします。未使用の開始条件でも繰り返し成功するか評価し、偶然の初成功と習得を分けます。未達成の結果も残します。

実装は **データと計算負荷の確認 → 身体の検証 → 一脳 → 三脳の並行比較 → 成長の可視化** の順に進めます。

実験条件、成功判定、学習範囲、実装順序、出典は [PLAN.md](PLAN.md) を参照してください。公式データやVRMモデルを配布する際は、それぞれの利用条件とクレジットに従います。
