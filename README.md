# MultiBrain Lab

**三つの脳が、一つの身体を動かせるようになるまで。**

ハエの中枢神経系の配線データ（MaleCNS）から作った神経モデルを人型身体に接続し、床から起き上がって立つ動作を強化学習で獲得させる実験である。
一脳で全身を動かす条件と、三脳で分担や協調をさせる条件を同じ身体、同じ報酬で並列に走らせ、学習の速さ、姿勢の安定、脳同士の協調、脳間結合の効き方を比べる。
学習の進み方と失敗は、美少女アバターと、脳の競合を文章にする語り手で表示する。

個人で進める研究で、現在は実装前の設計段階にある。
このリポジトリには計画文書だけがある。

## 比較する条件

| 条件 | 構成 |
|---|---|
| `mono` | 一脳が 27 自由度の全身を操作する |
| `tri_symmetric` | 三脳がそれぞれ全身への操作案を出し、平均する |
| `tri_body` | 三脳が左側 11、中央 5、右側 11 の自由度を分担する |
| `tri_linked` | `tri_body` の分担に、脳をまたぐ合成シナプス結合を加える |
| `mlp_control` | 通常の MLP 方策で全身を操作する基準 |

主比較の後に、三つの MLP、学習を止めた神経中核、接続先を入れ替えた同規模ネットワーク、細胞型ごとにパラメータを共有した変種を対照として加える。

## 設計の要点

- **神経モデル**：各ニューロンを膜電位と入力電流の二変数で更新する。初版は出力を連続値（ロジスティック関数）で表し、次版は同じ式のまま出力を発火（LIF）に切り替えて代理勾配で学習する。学習するのはニューロンごとの増幅率、バイアス、二つの時定数で、配線と符号は固定する。
- **入出力の割当**：関節角度は脚の弦音器へ、接触は鐘状感覚子へ、重力方向はジョンストン器官へ、というように、MaleCNS の感覚ニューロン注釈で入力先を決める。トルクは標的筋の注釈で選んだ運動ニューロン群から、主動筋と拮抗筋の差として読み出す。腕は前脚、脚は後脚に対応づける。
- **身体**：身長 1.58 m、質量 50 kg、27 自由度の人型を MuJoCo XML で定義する。関節ごとの可動域と上限トルク、体節の質量比、センサ構成は計画に表で置いてある。
- **脳間結合**：`tri_linked` では、脳 A の下行性ニューロンを脳 B の神経索に、脳 B 自身の結線を写した合成シナプスで接続する。重みと勾配は結合を通って流れ、どの細胞型が通信に使われたかを配線の言葉で読める。
- **監視と語り**：三脳のトルク案、報酬の内訳、結合の活動を事象として記録し、競合指数や支配率を計算する。規則に基づく語り手がそれを一行の文にし、アバターの横に流す。後で言語モデルに差し替えられる。
- **視覚の接続点**：頭部の測距センサから得た低解像度の深度を、視覚投射ニューロンの受容野に合わせて注入する経路を拡張条件として設計してある。

## 到達目標

予算の単位は身体を一回操作する身体ステップ（20 ms）である。

| 目標 | 内容 |
|---|---|
| G1 | MLP 方策が起き上がりを 2×10^8 身体ステップ以内に習得する |
| G2 | 一脳が同じ課題を 5×10^8 身体ステップ以内に習得する |
| G3 | 三脳条件を同じ予算で走らせ、協調と結合の指標を含む比較結果を出す |
| G4 | LIF 版が立位維持を 1×10^8 身体ステップ以内に習得する |

習得は、学習に使わない 24 個の開始姿勢で 20 回以上成功する評価が 2 回続くことと定義する。
予算内に達しなかった条件も同じ形式で記録し、原因を切り分ける。

実装は **データと計算量の実測 → 身体と MLP → 一脳 → 三脳と結合と監視 → 本比較 → LIF と視覚** の順に進める。
計算環境は RTX 5090 と Ryzen 9 9950X3D を想定し、Python、PyTorch、TorchRL、MuJoCo Warp で学習し、Three.js と VRM で表示する。

設計の詳細、更新式、ポートの割当規則、身体の XML、報酬、マイルストーンは [PLAN.md](PLAN.md) を参照。
